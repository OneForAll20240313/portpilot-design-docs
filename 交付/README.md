# 交付说明

本目录用于存放 PortPilot 的交付阶段文档，包括发布说明、变更日志与交付策略。

## 当前状态
- 项目尚处于设计/研发阶段，暂无正式发布版本。
- 本仓库为纯文档仓库，不存放二进制安装包、发行包或构建产物。

## 计划内容
- `release-notes.md` — 正式版本发布时记录各版本的发布说明
- `changelog.md` — 变更日志，记录功能新增、修复与调整
- 交付策略文档 — 版本号规范、发布流程、回滚方案

## 说明
- 涉及 devel 发行 deb 包等构建产物，请访问对应代码仓库的 release 页面。
- 本目录仅归档交付相关的文字性文档。
