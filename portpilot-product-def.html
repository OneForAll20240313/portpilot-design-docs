01产品概述

明确产品的定位、目标用户与核心价值主张。

1.1 产品定位

PortPilot 是一款面向嵌入式开发、设备调试与数据采集场景的串口通信调试工具。它以"会话"为核心组织单位，支持多设备并行管理，覆盖从裸字节收发、协议解析、终端 shell 交互到数据可视化的完整调试链路。

1.2 目标用户

嵌入式开发工程师

需要连接开发板、MCU、传感器，查看串口日志与调试信息。

设备调试 / 测试工程师

需要抓包分析、协议收发、批量命令与自动化测试。

运维 / 现场支持

需要快速连接现场设备、进入设备 shell、执行诊断命令。

数据采集分析人员

需要将串口数据流解析为结构化的可视化指标看板。

1.3 核心价值

  • 会话化组织：每个物理设备/连接对应一个独立会话，参数、模式、视图、缓冲全部随会话保存与切换，避免反复配置。
  • 模式互斥清晰：字节流与终端是两类对立工作模式，一次只进入一种，避免界面混乱。
  • 在线/离线状态驱动：会话状态决定哪些参数可编辑，杜绝连接中误改串口参数导致连接异常。
  • 强搜索与可视化：字节流支持多关键字多色高亮与前后导航；协议数据可配置为可视化看板。
  • 可定制外观：13 种主题 + 自定义主色 + 背景图蒙版，满足不同光照与个人偏好。

1.4 名词约定

名词定义
会话一条独立的外部连接，包含连接参数、缓冲参数、视图模式、运行状态与统计。
视图模式（View Mode）会话创建时选定，决定该会话开放哪些视图。仅两类：字节流 与 终端。
在线 / 离线会话运行状态。在线=连接成功，离线=未连接/断开/连接失败。
视图（View）会话内的内容页：字节流、终端、协议。同一模式下同时只显示一个。
模块（Module）独立的功能区：可视化、命令自动化、设置。可与会话视图互斥切换。
搜索标签（Chip）字节流里一个关键字筛选项，可独立着色、选中、定位。

02全局布局与基础框架

软件占满整个页面，采用固定高度组件 + 弹性工作区，整体最小尺寸约束，滚动条统一风格。

2.1 全屏布局

软件不再使用独立属性面板，而是占满整个 Web 页面，无右侧大块留白。整体采用弹性（Flex）纵向结构：顶部栏 + 主体区 + 状态栏。

2.2 最小尺寸

由于软件含固定高度控件，页面设置最小尺寸：最小宽 1024px、最小高 640px。低于该尺寸时出现滚动而不是压缩破坏布局。

2.3 统一滚动条

全局滚动条风格统一：宽度 9px，轨道为背景色，滑块为深灰圆角，hover 时变为主题主色，四角透明。

03会话管理

会话是产品的核心对象。本产品不存在"草稿会话"，新建即完成，创建后可直接连接。

3.1 会话列表结构

左侧会话面板包含：顶部"会话 + 新建"标题、会话搜索框、可折叠的会话分组树、底部当前会话详情。

元素说明
会话分组可折叠（▾/▸），如"现场设备""离线设备"，显示分组内会话计数。
会话节点状态点 + 名称 + 波特率徽标 + 模式标签（字节流/终端）+ 更多按钮 ⋯。
会话搜索按名称过滤会话，无匹配的分组自动隐藏。
会话详情当前会话的设备名、波特率、连接时长、RX/TX 计数，提供"详情""导出日志"按钮。

会话详情模态框

点击"详情"弹出会话详情模态框，展示当前会话的完整只读信息：设备、端口（如 COM3 · 115200 · 8N1）、VID:PID、连接时长、RX/TX 计数、缓冲占用。

导出日志

点击"导出日志"将当前会话日志导出为文件（如 portpilot-deviceA.log）。

原型数据提示：参考原型 v15 中"离线设备"分组内的"PLC 控制器 · COM5"节点状态为在线（data-state="online"），与分组名不符，属原型演示数据瑕疵。正式实现应以会话节点状态为准，分组归属由状态驱动。

3.2 会话状态（在线 / 离线）

会话有明确运行状态，状态决定哪些参数可编辑。列表节点用状态点标识：绿=在线、红=离线。

状态触发可修改参数
在线连接成功仅会话名、视图模式、显示类（编码/时间戳/自动换行）与缓冲参数可即时调整；连接参数（端口/波特率/数据位/停止位/校验）置灰不可改。
离线连接失败 / 启动未连接 / 断开连接参数 + 缓冲参数 + 会话名 + 视图模式全部可改。

3.3 会话模式（View Mode）——互斥关系

会话在创建时选定模式，模式决定该会话开放哪些视图。字节流模式与终端模式是对立的两类：

模式开放视图可视化适用场景
字节流模式字节流 + 协议（同时只显示一个）开放抓包 / 协议解析 / 数据分析
终端模式仅终端不开放直连设备系统 shell

3.5 新建后的交互逻辑

创建并连接

点击"创建并连接"后，会话加入列表并自动选中，无草稿态。

按模式初始化

字节流模式进入字节流默认视图；终端模式进入终端视图。

立即尝试连接

创建后直接连接，默认进入在线状态。

失败不删除

连接失败不会删除会话，而是转为离线状态，用户可在会话设置中修改波特率等参数后重试。

清理搜索残留

新会话创建后清空残留的搜索标签，避免继承旧筛选。

若在其他页面点击"新建"后又关闭，新建会话不保留未完成标签；只有真正"创建"才会生成会话。会话管理无草稿概念。
"连接失败转为离线、不删除会话"为本产品明确规则。参考原型 v15 的 createSession 当前未模拟创建后连接失败分支（恒置在线），正式实现需补充该状态流转：创建后尝试连接，失败则置为离线并允许在会话设置中改参重试。

3.6 会话右键菜单

在会话节点上右键（或点击 ⋯）弹出会话右键菜单，它是会话管理各功能的快捷入口，核心功能都在设置界面完成。

菜单项行为条件
连接将会话置为在线仅离线会话显示
断开将会话置为离线仅在线会话显示
会话设置打开会话设置弹窗始终
重命名提示框改名始终
复制会话克隆参数生成离线副本始终
删除会话确认后移除始终（红色危险项）

3.7 复制会话

复制会话不用重新填写参数，克隆源会话的连接、缓冲、模式参数，生成一个离线副本：

  • 命名：源名 + "（副本）"，冲突时递增后缀"（副本 2）""（副本 3）"…
  • 参数继承：端口、波特率、数据位、停止位、校验、缓冲策略/大小/溢出策略、视图模式全部克隆。
  • 状态：副本初始为离线，需手动连接。
  • 统计不继承：RX/TX 计数、连接时长等运行时统计不复制。
  • 插入位置：插入源会话所在分组，加入后自动选中并清理搜索残留。
命名格式以本定义为准（全角括号"（副本）"）。参考原型 v15 当前使用半角括号 (副本)，正式实现需按本定义统一为全角。

3.8 会话选择联动

点击会话节点时，全产品联动刷新：左侧详情、顶部全局状态、会话管理面板、字节流状态摘要、视图模式。若当前处于模块页：设置页内保持设置页以便连续对比；其他模块返回该会话视图并重新应用模式。

状态栏的 TX/RX 计数、速率、缓冲占用为当前会话的只读统计展示，产品目标为随会话切换联动刷新。参考原型 v15 中状态栏当前为静态示例数据，正式实现需接入会话统计联动。

04会话设置与通讯测试

会话设置是所有参数修改的核心界面，可从右键菜单或字节流"会话设置"按钮进入，内置通讯测试。

4.1 入口

  • 右键菜单 → 会话设置：会话管理功能的快捷入口，打开会话设置弹窗。
  • 字节流视图 → 会话设置按钮：顶部只读状态摘要旁的按钮。
  • 设置中心 → 会话管理：内嵌同字段的会话管理面板。

4.2 字段定义

字段选项 / 类型在线时可改
会话名称文本输入✔
视图模式字节流 / 终端✔（切换后立即应用模式）
端口 / 地址下拉✘ 置灰
波特率下拉✘ 置灰
数据位8/7/6/5✘ 置灰
停止位1/1.5/2✘ 置灰
校验位None/Even/Odd✘ 置灰
缓冲策略环形/追加/双缓冲✔
缓冲大小16MB/1MB/4MB/64MB✔
溢出策略停止接收/丢弃最旧✔
在线会话：连接参数（端口/波特率/数据位/停止位/校验）不可修改，需先断开。离线会话：全部参数可修改。

4.3 通讯测试

会话设置弹窗内置通讯测试功能，用于判断端口能否打开：

  • 点击"测试端口"后，根据所选端口判断能否打开。
  • 端口可打开 → 显示绿色"✓ 通讯正常，端口可打开"。
  • 端口被占用/不存在 → 显示红色"✗ 无法打开，端口可能被占用或不存在"。
  • 通讯测试仅验证端口能否打开，不改变会话状态。
连接与断开操作集中在会话设置界面完成；字节流视图不再保留可编辑的波特率/选串口/连接/数据位等控件，顶部仅保留只读状态摘要（连接状态点 + "已连接 · 波特率 bps" + 会话名）。

05视图体系与互斥关系

产品采用"视图 + 模块"两层结构，均遵循互斥原则，同一时刻只显示一个。

5.1 设计原则

  • 会话内视图互斥：字节流、终端、协议同一模式内同时只显示一个，不可能同时看到字节流+终端+协议。
  • 模式决定视图：字节流模式开放字节流+协议；终端模式只开放终端。
  • 模块独立互斥：可视化、命令自动化、设置作为独立模块，与会话视图互斥切换，并有"← 返回视图"按钮还原离开前的视图。

5.2 视图标签栏

视图标签栏位于工作区顶部，按当前会话模式显示对应标签：

会话模式视图标签额外模块按钮
字节流字节流 / 协议可视化、命令自动化、设置
终端终端命令自动化、设置（可视化隐藏）
字节流与协议是互斥的（同时只显示一个），但两者都属于字节流模式，共用可视化。终端模式不开放可视化。

5.3 模块返回机制

进入可视化/命令/设置模块时，记录离开前的会话视图（lastView）；点击"← 返回视图"或重新选择会话时，还原到该视图。设置模块内切换会话时保持设置页以便连续对比参数。

06字节流视图

字节流视图用于裸数据收发、抓包与关键字检索，是默认的核心工作区。

6.1 顶部只读状态摘要

连接状态点 + "已连接 · 波特率 bps"（或离线）+ 会话名。仅会话设置按钮可操作，无连接参数编辑控件。

6.2 接收工具栏

控件选项
编码ASCII / HEX / UTF-8
暂停开关，冻结接收刷新
时间戳开关
换行开关（默认开）
清空清空接收区
缓冲参数（缓冲策略/缓冲大小/溢出策略）入口已收拢到会话设置与会话管理面板，不在字节流工具栏重复提供，避免多个入口导致的配置不一致。

6.3 搜索栏（两行布局）

搜索区采用两行布局：

  • 第一行（搜索栏）：搜索输入框 + 添加按钮 + 高亮开关 + 命中统计 + 上一条 ← / 下一条 → 导航。
  • 第二行（标签行）：所有已添加的搜索标签（chip）胶囊，超过一行可折叠（展开/收起）。

搜索标签（Chip）交互

标签调色板

  • 35 种预设色：7 基色（红/橙/黄/绿/青/蓝/紫）× 5 档亮度（0.6/0.8/1.0/1.2/1.4）。
  • 7 个自定义色槽：可保存自定义颜色，点击应用。
  • 自定义取色：颜色选择器 + 槽位选择 + 保存。

多标签颜色区分

搜索到多个关键字时必须自动换色，保证多标签可区分。新标签自动分配未被占用的颜色；命中处高亮背景与标签颜色一致，前缀标签无自定义色时回退默认橙色。

07终端视图与自动化命令

终端视图直连设备系统 shell，无需独立输入框，直接在终端区键入；下方提供自动化命令面板。

7.1 终端交互

  • 无独立输入框：直接在终端区域键入，命令显示在光标行（带闪烁光标）。
  • 回车提交：提交当前输入并回显结果。
  • 退格：删除字符。
  • 提示符：root@device:~$，主题色。
  • 编码：UTF-8 / ASCII / HEX 可选。
  • 回显 / 清屏 / 重置：控制输出。

7.2 自动化命令面板

终端下方提供"⚡ 自动化命令 · 点击快捷发送"面板，一键发送常用命令：

命令说明

ping {ip} -c 4网络连通（带占位符 {ip}）

终端模式仅开放终端视图，不开放字节流、协议与可视化。终端下的主题切换要考虑可读性，默认蓝色可视化效果差时可切换主题改善。

08协议视图

协议视图用于帧结构解析与组帧编辑，属于字节流模式的一部分。

8.1 协议树

左侧协议定义树：可折叠展开协议（如 Modbus RTU、YMODEM），显示字段与类型（uint8/uint16/bytes 等），支持 +添加、自定义协议。

8.2 右侧页签

页签内容
解析结果字段/值/说明表格，如地址、功能码、起始地址、寄存器数量、CRC16（含校验通过状态）。
组帧编辑模板（读取/写入寄存器）、地址、功能码，实时预览帧（如 7E 01 03 00 00 04 7E）。
模板协议模板管理。

8.3 组帧操作

提供批量组帧、回环验证、保存模板、发送等操作。

09可视化模块

9.1 组件库

  • ▣ 数值显示
  • ◉ 仪表盘
  • 📈 折线图
  • 📊 柱状图
  • ◐ 开关
  • 🔷 3D 姿态

9.2 画布

网格背景画布，组件可自由拖放定位。顶栏提供：看板模板（默认/温度监控/传感器面板）、保存画布、应用。组件可缩放。

9.3 属性面板

选中组件后在右侧属性面板编辑：标题、数据源（字段池）、刷新频率等。

终端模式不开放可视化。可视化独立于字节流/协议视图存在，字节流与协议视图均可进入。

11.2 自定义主色

颜色选择器手动选择任意颜色作为主色，仅覆盖主色变量，不改变其他主题色。

11.3 背景图片与蒙版

主题设置中可填入图片 URL 或选择本地图片作为背景。由于背景图颜色可能与主题字体相近导致看不清，提供蒙版方案：

  • 蒙版透明度滑杆（30%~90%，默认 55%）。
  • 蒙版为深色半透明覆盖层，保证背景图下文字始终清晰可读。
  • 所有主题色可通过预设或自定义调整，配合蒙版应对任意背景图。
