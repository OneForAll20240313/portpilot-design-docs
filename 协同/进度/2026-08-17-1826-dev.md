## 实现内容（Qt-free 内核 + Qt 信号薄壳分层）

**Service 层 Qt-free 内核 `BufferService`**（`src/service/buffer_service.{h,cpp}`）：
- A-301 `onData`/`pushData(connectionId, bytes)` → 经 Core EventBus 发射 `buffer.dataReceived` 事件，载荷 `{connectionId, bytes, timestamp}`，对齐 events.md。
- `onDataReceived(handler)` 订阅 / `off(id)` 取消 / `dataReceivedListeners()` 查询，供上层（UI 薄壳）订阅。
- Qt-free，不依赖 Qt，纳入现有 CI。不 new Core 设备，仅依赖 `domain::DevicePort` 语义与 EventBus（单向依赖）。

**UI 层 Qt 信号薄壳 `QtSignalBridge`**（`src/ui/qt_signal_bridge.{h,cpp}`）：
- `QObject` 派生 + `Q_OBJECT`，构造订阅 BufferService.buffer.dataReceived → 发射 Qt 信号 `dataReceived(connectionId, bytes)`。
- 桥接中不触碰 Core/Domain 设备实现（符合 13.7），Qt 信号/槽机制保证无跨线程问题。
- 冲突处理：core::EventBus::emit 与 Qt `emit` 宏冲突 → UI 与主程序 `QT_NO_KEYWORDS`，信号发射用 `Q_EMIT`、信号段用 `Q_SIGNALS`。

**main.cpp**：装配演示链路 SerialWorker→BufferService→QtSignalBridge，offscreen 探针驱动两帧注入数据。

**单测**：`tests/unit/buffer_service_test.cpp`（BufferService 4 例）：载荷完整性/取消订阅/订阅计数/空 handler 拒绝。tests/CMakeLists 登记 + 链接 portpilot_service。
